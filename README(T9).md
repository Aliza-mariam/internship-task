# 💊 Medicine Availability Finder

## Project Overview

Medicine Availability Finder is a web application that helps users quickly find medicines available in nearby pharmacies.
Instead of visiting multiple pharmacies, users can search for a medicine and view where it is currently available.

---

## Problem Statement

Many people waste time searching for medicines because they do not know which pharmacy has the required medicine in stock. 
This application aims to solve that problem by providing real-time medicine availability information.

---

## Objectives

- Search medicines easily
- View pharmacy details
- Check medicine stock
- Help pharmacy owners update inventory
- Save users time
