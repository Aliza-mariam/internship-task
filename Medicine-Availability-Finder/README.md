# Medicine Availability Finder

## Project Overview

**Medicine Availability Finder** is a simple web application that helps users search for medicines and check their availability at different pharmacies.

The application allows users to search for a medicine, check its availability status, view pharmacy information, stock quantity, and price.

---

## Main Features

### 1. Home Page

The Home Page provides:

- Simple and user-friendly interface
- Medicine search box
- Find Medicine button
- How It Works section
- Navigation menu
- Footer section

Users can enter a medicine name in the Home Page search box and directly search for it.

---

### 2. Find Medicine Page

The Find Medicine page allows users to:

- Search medicines by name
- Check medicine availability
- Check whether medicine is out of stock
- View pharmacy name
- View pharmacy location
- View stock quantity
- View medicine price
- View medicine details

---

### 3. Medicine Database

The current application contains sample medicine data including:

- Panadol
- Paracetamol
- Brufen
- Ibuprofen
- Amoxicillin
- Azithromycin
- Cetirizine
- Loratadine
- Omeprazole
- Vitamin C
- Aspirin
- Diclofenac
- ORS
- Metformin
- Cough Syrup

The medicine data is currently stored in JavaScript for demonstration purposes.

---

### 4. Dashboard

The project includes a Dashboard page that provides an overview of the medicine availability system.

---

## Technologies Used

The project is developed using the following technologies:

- **HTML5** – Used to create the structure of web pages.
- **CSS3** – Used for styling, layout, colors, and responsive design.
- **JavaScript** – Used for medicine search, filtering, medicine data, and dynamic results.
